# Nekomimi

装備できる猫耳としっぽを追加する Minecraft Forge mod です。装備するとキャラクターの見た目が変わります。

- Minecraft 1.20.1 / Forge 47.4.28
- 依存mod なし（Forge 単体で動作）

## アイテム

色は 白・黒・オレンジ・灰色 の4種類です。

| アイテム | 装備スロット | ID |
| --- | --- | --- |
| 猫耳 | 頭 | `nekomimi:nekomimi_<color>` |
| 猫のしっぽ | 脚 | `nekomimi:neko_tail_<color>` |

`<color>` は `white` / `black` / `orange` / `gray` です。クリエイティブタブ「猫耳としっぽ」から入手できます。

- 通常版は防御力・耐久値がなく、見た目専用です（エンチャント不可）。金属版にすると防御力が付きます（下記）
- しっぽは6つの関節がつながった形で、ばねの物理演算で動きます（下記「しっぽの動き」）
- 手持ちのヘルメット・レギンスとは同じスロットを使うため併用できません

## レシピ

羊毛は色ごとに対応する色のものを使います（例: 白い猫耳 = 白い羊毛）。`W` = 羊毛、`L` = 革。

```
猫耳                しっぽ
W _ W               _ _ W
W L W               _ W _
                    L W _
```

## 金属版（防御力付き）

猫耳またはしっぽを作業台の中央に置き、周り8マスをインゴットで囲むと、見た目はそのままで **その金属のヘルメット／レギンスと同じ性能** になります（防御力・強靭さ・耐久値・エンチャント適性・金床での修理）。

```
I I I
I X I      X = 猫耳 または しっぽ（通常版）
I I I      I = 下表の素材
```

| 金属版 | 素材 (I) | 猫耳の性能 | しっぽの性能 |
| --- | --- | --- | --- |
| 鉄 | 鉄インゴット | 鉄のヘルメット | 鉄のレギンス |
| 金 | 金インゴット | 金のヘルメット | 金のレギンス |
| ダイヤモンド | ダイヤモンド | ダイヤのヘルメット | ダイヤのレギンス |
| ネザライト | ネザライトインゴット | ネザライトのヘルメット | ネザライトのレギンス |

- 色（白・黒・オレンジ・灰色）は引き継がれます。アイテム名の末尾に金属名が付きます（例: 白い猫耳（鉄））
- ネザライト版は炎・溶岩で燃えません
- 金属を変えたい場合は、通常版から作り直してください

## しっぽの動き

しっぽは見た目だけの物理演算で動きます。サーバーには何も送らず、ゲームの動作や当たり判定には影響しません。他のプレイヤーのしっぽも、それぞれの動きに合わせて動きます。

- 立っているとき: ゆっくりゆらゆら揺れます
- 走る: 後ろへ流れ、止まると前へ振れ戻ってから落ち着きます
- 横へ移動: 反対側へ流れます
- 旋回: 体の向きを変えると、遅れて反対側へ振れます
- ジャンプ: 下へ押さえつけられ、落下すると持ち上がります

先端ほどやわらかいばねなので、先に行くほど遅れてしなります。フレームレートによる動きの違いはありません。動きの強さは `TailSimulation`（物理）の定数で調整できます。

## ふわふわの毛

猫耳としっぽは、重ねた多層の殻（シェル）で毛皮を表現しています。1つの部品を、少しずつ大きくした11枚の箱として重ね、外側の箱ほど毛先の細い点だけを残すので、輪郭がふわっとした細かい毛に見えます（ブロック1個あたり64×64のテクスチャで描いています）。色ごとに、根元が濃く毛先が明るい毛、オレンジの縞、しっぽの先、耳の内側のうぶ毛を描き分けます。

- 動くと毛が逆方向へなびき、自重で少し垂れます。外側の毛ほど大きく動きます
- 猫モードの感情で毛の様子が変わります: 驚き・威嚇は長く逆立って硬く、リラックスは短くしなやかで柔らかく、怖いは細かく震えます
- 見た目優先の作りで、しっぽ1本と猫耳でそれぞれ数百面を描きます。重いときは `FurLayout.SHELLS`（層の数）を減らし、`tools/generate_assets.py` でテクスチャを作り直してください
- `tools/preview_fur.py <色> <出力.png>` で、ゲームなしでおおまかな見た目を確認できます。ポーズは `tools/preview_pose.py <出力.png> [ポーズ名...]` で、色付きの箱で確認できます

## モード（通常モード・猫モード）

**Alt＋右クリック** で、通常モードと猫モードを切り替えます（コントロール設定で「モード切り替え」キーを割り当てても切り替えられます）。Altを押している間の右クリックは、アイテムの使用やブロックの設置には使われません。

### 通常モード
- 歩くと、歩くリズムに合わせて、しっぽがゆっくり揺れることがあります
- ダッシュすると、しっぽを後ろへまっすぐ伸ばします
- 急に向きを変えると、しっぽが左右に曲がります

### 猫モード
- プレイヤーが四足歩行の猫の姿になります（標準の「這う」姿勢は使わず、専用のポーズとモデルです）
- 当たり判定と視点の高さも、猫の大きさ（幅0.6×高さ0.7）になります
- 立っているときとスニーク中だけ猫の体になります。泳ぐ、寝る、エリトラ、乗り物では普通の体で表示されます
- 猫モードを解除するには、立ち上がれる空間が必要です
- 高さ1ブロックのすき間も、猫の姿のまま歩いて通れます（普通の体のように匍匐の姿勢にはなりません）
- **Gキー** で感情メニュー（パイメニュー）が開きます（ポーズは **Hキー**、下記）。扇形をクリックするか、Gを押したまま扇形の上で離すと選べます。中央は「ふつう」です。キーはコントロール設定で変更できます

| 感情 | しっぽの動き |
| --- | --- |
| 嬉しい | ピンと真上に立てる |
| リラックス | 体の横へ力を抜いて垂らす |
| イライラ | 低く構えて左右に大きく振る |
| 怖い | 後ろ足の間に巻き込み、細かく震える |
| 驚き・威嚇 | 毛を逆立てて太くし、背中の上でアーチを描く |
| 興味 | 低く静止し、先端だけを小刻みに動かす |
| 甘えたい | 横へ大きく巻きつく |

### 耳の表情
猫耳も感情に合わせて動きます（猫耳を付けているときだけ）。ばねで動き、ときどき片方がピクッと動きます。

| 感情 | 耳 |
| --- | --- |
| ふつう | ほぼまっすぐ。ときどきピクッ |
| 嬉しい | 少し前へ、ピンと立てる |
| リラックス | 少し後ろ、外側へ力を抜く |
| イライラ | 横へ倒す（イカ耳）。ピクピクと動く |
| 怖い | ぺたっと後ろへ伏せ、細かく震える |
| 驚き・威嚇 | 前へ立てる |
| 興味 | 前へ向ける。左右で向きが違い、よく動く |
| 甘えたい | 少し後ろ、外側へゆるめる |

通常モードでは、ダッシュすると耳が後ろへ寝て、落下中も寝ます。

### ポーズ
**Hキー** でポーズメニューが開きます。感情メニューと同じ操作です（中央は「立つ」）。

| ポーズ | 見た目 | しっぽ（感情が「ふつう」のとき） |
| --- | --- | --- |
| 座る | 上体を起こしてお座り | ゆったり垂らす |
| 香箱座り | 手足を体の下にしまって伏せる | ゆったり垂らす |
| 伸び | 胸を低く、腰を高く、前足を伸ばす（約2.5秒で自動で終わる） | ピンと上げる |
| 毛づくろい | 座って、片方の前足を口元へ。ペロペロと動く | ゆったり垂らす |
| 丸まって寝る | 香箱座りで頭を下げ、ゆっくり呼吸する | 巻きつける |

- 地面の上で、水や乗り物の中でないときに選べます
- 歩く・ジャンプする・ダメージを受けるとポーズは解除されます
- 感情と組み合わせられます（感情を選んでいればしっぽはその感情の動きになります）
- ポーズの切り替えはなめらかに移り変わります

### ロングジャンプ（猫モード）
**ダッシュ中にしゃがみ、そのしゃがみ中にジャンプ**すると、向いている方向へ約7ブロック飛びます（通常のダッシュジャンプは約4ブロック）。

- しゃがみ始めがダッシュ中、またはダッシュをやめて約0.2秒以内であることが条件です（しゃがむとダッシュが止まるため）。しゃがみ続けている間はいつでもジャンプできます
- しゃがみを離したあとも、約0.25秒（5ティック）以内ならロングジャンプになります（着地予告もその間は出ます）。それより後のジャンプは、ふつうのジャンプです
- 地面にいるときだけ出ます。着地するまで次は出せません
- ロングジャンプをすると、しゃがみは強制的に解除されます（キーを押したままでも立ちます。しゃがみ直すには、一度キーを離してからもう一度押します）
- **着地予告**: ジャンプできる状態（ダッシュ直後にしゃがんでいる間）は、飛んだ場合の軌道を線で、着地点を地面の四角い印で表示し、距離（ブロック数）をホットバーの上に出します。ブロックや天井にぶつかる場合もふまえた予測です（赤い線のときは着地点が遠すぎて表示できません）
- モーション: しゃがんだときは低く構えて、ロングジャンプ中は体を水平に伸ばして、上昇中は鼻先が上を、落下中は下を向きます（他のプレイヤーにも見えます）

### 犬かき（猫モード）
猫モードで水に入ると、人間の泳ぎ（腹ばい）ではなく、**猫の体のまま犬かき**をします。体を水平に浮かせて頭を水面に出し、前足を交互にかき、後ろ足でバタ足をします。泳ぐ速さに合わせて、かく速さも変わります（他のプレイヤーにも見えます）。足が底についている浅い水は、ふつうに歩くモーションです。

### マルチプレイ
モードと感情はサーバーが管理し、見えている全員に同期されます。サーバーにもこのmodが必要です。

## ビルド

Java 17 が必要です。

```
./gradlew build
```

成果物は `build/libs/nekomimi-1.0.0.jar` です。GitHub Actions でも push のたびにビルドされ、jar が artifact として保存されます。

開発用クライアントは `./gradlew runClient` で起動できます。

GitHub の Actions タブから `server-smoke-test` を手動で実行すると、modを入れた本物のサーバーを起動して、エラーなく立ち上がるかを確認できます（クライアント専用クラスの混入や通信登録の誤りを検出します。画面の描画は確認できません）。

## アセットの再生成

テクスチャ・アイテムモデル・レシピ・言語ファイルは `tools/generate_assets.py`（Pillow が必要）で生成しています。色の追加や見た目の調整はこのスクリプトと `NekoColor` を編集してください。

```
python3 tools/generate_assets.py
```
